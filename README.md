# rune-loot-filter

Custom OSRS loot filter based on [Storn's Iron-Filter](https://github.com/Storn42/Iron-Filter).

## What's changed

- Transparent item backgrounds
- Transparent borders
- Tier-colored item text (readable without the highlight boxes)

## Files

- `Iron-Filter-CUSTOM.rs2f` — current custom filter, tracking Storn's latest release
- `sync_transform.py` — regenerates the custom filter from a new upstream release

## Install

1. In RuneLite, enable the **Loot Filter** plugin.
2. Loot Filter panel → **Import** → select `Iron-Filter-CUSTOM.rs2f`.
